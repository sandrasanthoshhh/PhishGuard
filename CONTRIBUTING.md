# Contributing to PhishGuard

Thank you for your interest in PhishGuard.

## Development Guidelines

- Keep detection logic explainable.
- Avoid collecting or storing real credentials.
- Test changes using controlled local pages.
- Document new detection rules.
- Keep Chrome extension permissions as limited as practical.
- Do not add real phishing URLs or stolen credentials to the repository.

## Pull Requests

Please include:

1. What changed
2. Why the change was needed
3. How it was tested
4. Any new permissions or security implications
5. Screenshots for significant UI changes

## Security Issues

Do not publish sensitive exploit details, credentials, API keys, or personal data in issues.
